## 二、核心业务术语

### 2.1 主体

| 中文 | 英文 | 定义 |
|---|---|---|
| 用户 | User | 系统的注册使用者，数据归属的最小单位 |
| 角色 | Role | 用户的能力集合，共 guest、user、admin、super_admin 四种 |
| 访客 | Guest | 未登录，仅能通过分享 token 只读访问 |
| 管理员 | Admin | 可查看与管理全体用户数据的角色 |
| 超级管理员 | Super Admin | 拥有全部权限，含角色变更、系统配置、硬删除 |
| 账号 | Account | 用户在交易所的 API 凭证与所属环境，不等于交易所账户本身 |
| 插件 | Plugin | 一组策略实现的集合，含元信息、代码、参数定义 |
| 实例 | Instance | 账号 + 插件 + 参数 + 交易对 + 模式的组合，是唯一的运行单元 |
| 参数 | Parameter | 插件声明、用户填写的配置值 |
| 参数 schema | Parameter Schema | 插件对参数的声明：名称、类型、范围、默认值、是否必填 |
| 能力 | Capability | 插件声明自己支持的动作，如开仓、平仓、带保护开仓 |
| 能力声明 | Capability Declaration | 元信息中的能力清单，声明的能力必须有对应实现 |

### 2.2 交易

| 中文 | 英文 | 定义 |
|---|---|---|
| 订单 | Order | 一次下单请求及其状态与成交记录 |
| 持仓 | Position | 某个交易对上的净头寸及其成本与盈亏 |
| 成交 | Fill | 订单的一部分或全部实际成交的明细 |
| 平仓 | Close Position | 减少或清空持仓的动作 |
| 保护单 | Guard Order | 开仓时附带的下单，用于限制下行风险 |
| 保护缺失 | Guard Missing | 应有保护单但交易所与本地均不存在 |
| 撤单 | Cancel Order | 撤销尚未成交的订单 |
| 名义价值 | Notional Value | 数量 × 价格，用于校验交易所最小值 |
| 精度 | Precision | 交易对对数量与价格的小数位或步长限制 |
| 滑点 | Slippage | 预期成交价与实际成交价的差，模拟盘中按配置模拟 |
| 手续费 | Fee | 成交时收取的费用，模拟盘中按配置模拟 |
| 净值 | Equity | 余额加上未实现盈亏 |
| 快照 | Snapshot | 定时采样的净值与持仓记录 |
| 归一化 | Normalization | 把不同起始规模的净值曲线折算到同一基准，便于对比 |
| 回撤 | Drawdown | 净值相对历史峰值的下降幅度 |
| 熔断 | Circuit Breaker | 触发后只允许平仓不允许开仓的保护动作 |
| 冷却期 | Cooldown | 触发后一段时间内禁止特定开仓动作 |

### 2.3 运行

| 中文 | 英文 | 定义 |
|---|---|---|
| 实盘 | Live | 下单真实发往交易所 |
| 模拟盘 | Paper | 下单走本地模拟撮合，不产生真实成交 |
| 行情 | Market Data | 交易对的价格与深度数据 |
| 行情新鲜度 | Market Freshness | 行情距当前时间的延迟，超阈值则停止开仓 |
| 交易对 | Symbol | 交易标的，如 BTC/USDT |
| 环境 | Environment | 账号所属的交易所环境，如实盘与测试网 |
| 探活 | Health Check | 定时验证账号凭证是否仍然有效 |
| 对账 | Reconciliation | 以交易所数据为准，比对本地的订单与持仓并修正差异 |
| 对账差异 | Reconciliation Diff | 对账发现的本地与交易所不一致之处 |
| 未知状态 | Unknown State | 下单请求已发出但结果无法确定 |
| 收敛 | Convergence | 通过查询或推送把未知状态确定下来 |
| 兜底 | Fallback | 实时通道之外的第二条保障路径，如对账之于推送 |
| 幂等 | Idempotency | 同一请求重复执行不产生额外的副作用 |

## 三、模块与代号

| 中文 | 代号 | 职责 |
|---|---|---|
| 行情中心 | MarketHub | 统一拉取与分发行情 |
| 事件总线 | EventBus | 系统内事件的发布与订阅 |
| 策略调度 | Runner | 驱动实例的行情回调与生命周期 |
| 对账引擎 | Reconciler | 收敛未知状态与修正差异 |
| 模拟撮合 | PaperEngine | 模拟盘的下单撮合与账户维护 |
| 保护中心 | GuardHub | 开仓保护、保护缺失检测与同步 |
| 风控中心 | RiskEngine | 限额、熔断、回撤与冷却 |
| 连接池 | ClientPool | 按账号维护交易所连接与限频额度 |
| 用户数据流 | UserStream | 通过 WebSocket 接收账户变更 |
| 订单中心 | OrderCenter | 下单四段处理与状态维护 |
| 审计模块 | Audit | 记录关键操作的主体、时间、对象、结果、来源 |

模块代号只用于指代职责边界，不构成对实现语言、类名、目录结构的约定。

## 四、状态枚举

### 4.1 实例状态

| 值 | 含义 |
|---|---|
| `created` | 已创建，未启动 |
| `starting` | 正在启动（过渡态） |
| `running` | 正在运行 |
| `pausing` | 正在暂停（过渡态） |
| `paused` | 已暂停 |
| `stopping` | 正在停止（过渡态） |
| `stopped` | 已停止 |
| `error` | 出错（启动失败或运行时致命错误） |

### 4.2 订单状态

| 值 | 含义 |
|---|---|
| `pending` | 已创建，未提交 |
| `submitted` | 已提交交易所 |
| `partial` | 部分成交 |
| `canceling` | 正在撤单（过渡态） |
| `filled` | 完全成交（终态） |
| `canceled` | 已撤销（终态） |
| `rejected` | 被拒绝（终态） |
| `failed` | 失败（终态，含未知后收敛为失败） |

终态：`filled`、`canceled`、`rejected`、`failed`。

### 4.3 账号状态

| 值 | 含义 |
|---|---|
| `active` | 正常可用 |
| `abnormal` | 探活失败，暂时标记异常 |
| `invalid` | 密钥失效 |
| `disabled` | 被停用 |
| `deleted` | 已删除 |

### 4.4 用户状态

| 值 | 含义 |
|---|---|
| `pending` | 待邮箱验证，不能登录 |
| `active` | 正常 |
| `locked` | 因连续登录失败被锁定 |
| `disabled` | 被管理员禁用，不能登录，数据保留 |

## 五、易混词辨析

| 词对 | 区别 |
|---|---|
| 用户 / 账号 | 用户是人，账号是他在交易所的凭证；一个用户可有多个账号 |
| 账号 / 实例 | 账号是资源，实例是运行单元；一个账号可被多个实例使用 |
| 插件 / 实例 | 插件是代码与声明，实例是插件的运行副本；一个插件可派生多个实例 |
| 策略 / 插件 | 策略是业务逻辑，插件是策略的载体与打包形式 |
| 实盘 / 模拟盘 | 差别只在"下单走到哪里"，策略代码与行情完全共用 |
| 暂停 / 停止 | 暂停保留订阅与上下文，可快速恢复；停止释放订阅与上下文，恢复需重新启动 |
| 未定义 / 未实现 | 未定义指规则还没确定；未实现指规则已定但不在此文档范围 |
| 停止 / 删除 | 停止保留数据可再启动；删除清除数据不可恢复 |
| 禁用 / 删除（用户） | 禁用只拒绝登录、保留数据；删除是硬删除 |
| 熔断 / 冷却 | 熔断是账号级或全局级的开仓禁止，需明确解除；冷却是单币或策略的定时禁止，到时自动失效 |
| 对账 / 探活 | 对账比对订单与持仓；探活只验证凭证有效性 |
| 同步 / 对账 | 同步是推送驱动的实时更新；对账是定时驱动的兜底比对 |
| 净值 / 余额 | 净值含未实现盈亏；余额是账户可用与占用的资金 |
| 快照 / 审计 | 快照记录数值，用于画图与对比；审计记录行为，用于追溯 |
| 精度 / 步长 | 精度是小数位数；步长是最小变动单位，两者由交易所共同约束 |

## 六、命名约定

### 6.1 用词

- 中文文档统一使用本表的"中文"列，不混用同义词。
- 代码、配置、接口字段统一使用英文小写，多个词用下划线连接。
- 模块代号首字母大写，仅用于文档叙述。

### 6.2 特定用词约定

| 场景 | 采用 | 不采用 |
|---|---|---|
| 运行单元的实例 | 实例 | 策略实例、任务、机器人 |
| 交易所凭证 | 账号 | 密钥、API 账号（指代密钥时） |
| 本地模拟 | 模拟盘 | 纸上交易、测试盘 |
| 真实下单 | 实盘 | 真盘、生产交易 |
| 保护性挂单 | 保护单 | 止损单、止盈单（这类词由插件定义，框架不使用） |
| 状态收敛 | 对账 | 校验、校准 |

框架层不使用任何业务词（如杠杆、网格、止损），这类词只存在于插件的元信息与参数声明中。
