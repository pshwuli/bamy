# 前端页面结构

> 本文档是BAMY框架的第十份设计文档，定义：前端有哪些页面、每个页面展示什么、每个页面能做什么操作、策略与插件在前端如何呈现、页面之间的跳转关系、权限如何影响页面、交互细节如何规范。
> 不写代码，只写结构。本文档是完整设计，不是第一版，是最终态。

---

1. 前端分为几个区域
2. 每个角色看到哪些页面

4. 每个页面的字段从哪来

13. 响应式怎么做

## 二、前端的整体结构

### 2.1 四个区域

| 区域 | 使用者 | 说明 |
|---|---|---|
| 认证区 | 未登录用户 | 注册、登录、找回密码 |
| 用户后台 | 普通用户 | 看自己的账号、实例、模拟盘、策略、插件 |
| 管理员后台 | 管理员 | 看所有人的，运维全局 |
| 访客视图 | 任何有分享token的人 | 只读看一个盘 |

### 2.2 角色与页面的对应

| 页面 | guest | user | admin | super_admin |
|---|---|---|---|---|
| 注册/登录 | ✓ | - | - | - |
| 用户后台 | - | ✓ | ✓ | ✓ |
| 管理员后台 | - | - | ✓ | ✓ |
| 超级管理员后台 | - | - | - | ✓ |
| 访客视图 | ✓ | ✓ | ✓ | ✓ |

### 2.3 前端的整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                        顶栏                                   │
│  Logo | 通知 | 用户菜单 | 主题切换                            │
├──────────┬───────────────────────────────────────────────────┤
│          │                                                   │
│  侧边栏  │                    主内容区                       │
│          │                                                   │
│  导航菜单 │              （每个页面渲染在这里）                │
│          │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│                        底部状态栏（可选）                     │
│  引擎状态 | 版本号 | 当前时间                                 │
└──────────────────────────────────────────────────────────────┘
```

技术选型：Vue 3 + Element Plus，构建用 Vite，状态管理用 Pinia，路由用 Vue Router。版本见《部署与运行》第三节。

### 2.4 响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| 桌面 | ≥1280px | 侧边栏展开 |
| 平板 | 768-1279px | 侧边栏折叠 |
| 手机 | <768px | 侧边栏抽屉 |

## 三、认证区

### 3.1 登录页

路径： /login

结构：

- 居中卡片
- Logo
- 用户名输入框
- 密码输入框
- 2FA输入框（如开启）
- 登录按钮
- 忘记密码链接
- 注册链接（如开启注册）

操作：

- 提交登录
- 跳转忘记密码
- 跳转注册

错误展示：

- 用户名或密码错误 → 红字提示
- 账号被锁定 → 显示剩余时间
- 账号被禁用 → 提示联系管理员

### 3.2 注册页

路径： /register

结构：

- 用户名输入框
- 邮箱输入框（如开启）
- 密码输入框
- 确认密码输入框
- 邀请码输入框（如开启）
- 注册按钮
- 已有账号链接

操作：

- 提交注册
- 跳转登录

校验：

- 前端实时校验（长度、格式）
- 后端兜底

### 3.3 找回密码页

路径： /forgot-password

结构：

- 邮箱输入框
- 发送按钮
- 返回登录链接

操作：

- 提交邮箱
- 展示“已发送”提示

### 3.4 重置密码页

路径： /reset-password?token=xxx

结构：

- 新密码输入框
- 确认密码输入框
- 重置按钮

操作：

- 提交重置
- 跳转登录

### 3.5 初始化页

路径： /setup

条件： 仅当系统无任何用户时可见。

结构：

- 提示语“首次使用，请创建管理员”
- 用户名输入框
- 密码输入框
- 确认密码输入框

## 四、用户后台

### 4.1 整体结构

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：Logo | 通知 | 用户菜单 | 主题切换                      │
├─────────────┬────────────────────────────────────────────────┤
│ 侧边栏      │                                                │
│             │                                                │
│ · 总览      │                                                │
│ · 账号      │                                                │
│ · 策略      │                                                │
│ · 插件市场  │                                                │
│ · 我的插件  │主内容区                                        │
│ · 实例      │                                                │
│ · 订单      │                                                │
│ · 模拟盘    │                                                │
│ · 审计      │                                                │
│ · 设置      │                                                │
│             │                                                │
└─────────────┴────────────────────────────────────────────────┘
```

导航分三组：

| 分组 | 菜单项 | 说明 |
|---|---|---|
| 交易 | 总览、账号、实例、订单、模拟盘 | 用户自己的交易资源 |
| 扩展 | 策略、插件市场、我的插件 | 策略只读，插件可安装可管理 |
| 其他 | 审计、设置 | 追溯与个人偏好 |

### 4.2 总览页

路径： /dashboard

结构：

顶部卡片区（4到6个）：

- 我的账号数
- 我的实例数（运行中 / 总数）
- 我的模拟盘数
- 今日订单数
- 今日盈亏（模拟盘合计）
- 当前告警数

中部区域：

- 左：我的实例运行状态（小型列表，最多5个）
- 右：我的最近订单（小型列表，最多5条）

下部区域：

- 我的账号健康（最多5个）
- 我的最近告警
- 已安装插件的异常提示（如存在）

操作：

- 点击卡片跳转对应页面
- 点击实例跳转实例详情

刷新：

- 通过WebSocket实时更新

### 4.3 账号页

路径： /accounts

结构：

顶部：

- 标题“我的账号”
- 搜索框（按名字）
- 筛选：状态、环境、交易类型
- 按钮：新增账号、批量导入

列表：

| 列 | 说明 |
|---|---|
| 账号名 | 点击进详情 |
| API Key | 脱敏显示（前4后4） |
| 环境 | 主网 / 测试网 |
| 交易类型 | 现货（当前唯一取值） |
| 只读 | 标签 |
| 状态 | 在线 / 离线 / 异常 / 失效 |
| 绑定实例数 | 数字 |
| 最后活跃 | 时间 |
| 操作 | 编辑、验证、删除 |

操作：

- 新增账号 → 弹窗表单
- 编辑账号 → 弹窗表单（只能改名字、只读、备注）
- 更新密钥 → 弹窗表单
- 验证 → 调接口，展示结果
- 查看余额 → 弹窗或跳详情
- 删除 → 二次确认

详情页：

路径： /accounts/{id}

Tab：

- 概览：账号信息、状态、最近验证
- 余额：实时余额
- 持仓：当前持仓
- 实例：绑定的实例列表
- 订单：该账号的订单
- 健康：健康数据、探活记录
- 审计：账号相关操作

### 4.4 策略页

路径： /strategies

本页由原插件页改造而来，只列策略包。

#### 4.4.1 顶部

- 标题“策略”
- 搜索框（按名字、作者）
- 筛选：标签、能力、加载状态

#### 4.4.2 策略卡片

每张卡片展示以下字段，并带两个按钮：查看详情、创建实例。

| 字段 | 说明 |
|---|---|
| 图标 | 策略包声明的图标，缺省时用默认图标 |
| 策略名 | 元信息中的显示名 |
| 版本 | 语义化版本 |
| 作者 | 元信息中的作者，可为空 |
| 描述 | 元信息中的描述，超出两行折叠 |
| 标签 | 元信息中的标签数组 |
| 参数数量 | 参数schema的条数 |
| 能力徽标 | 能力声明中为真的项，逐项一个徽标 |
| 加载状态 | 已加载 / 加载失败 / 待更新 |

能力徽标（只有声明为真的能力才展示）：

| 能力 | 徽标文案 |
|---|---|
| close_position | 平仓 |
| close_positions | 批量平仓 |
| close_all | 全平 |
| cancel_order | 撤单 |
| list_positions | 持仓清单 |
| pause | 暂停 |
| resume | 恢复 |

#### 4.4.3 失败策略区

- 与正常卡片分开展示，位于列表下方
- 展示策略名、失败原因、处理建议

| 展示项 | 说明 |
|---|---|
| 策略名 | 目录名 |
| 失败原因 | 元信息缺失、元信息格式错、参数schema非法、声明的能力无对应实现等 |
| 加载状态 | 加载失败 |
| 处理建议 | 由管理员修正策略文件后重新扫描扩展 |

#### 4.4.4 操作与说明

操作：

- 查看详情 → 弹窗展示参数schema与说明
- 创建实例 → 跳创建实例页，并预填该策略

说明：

- 策略是全局共享的，不区分用户
- 用户不能上传策略
- 用户不能删除策略
- 策略的增删由管理员在扩展目录上完成，用户端只读

### 4.5 插件市场

路径： /plugins

本页为新增页面，与策略页并列，只列插件包。

#### 4.5.1 顶部

- 标题“插件市场”
- 搜索框
- 筛选：作用域（全局 / 用户 / 账号）、是否出网（出网 / 不出网）、加载状态（已加载 / 加载失败 / 待更新）

#### 4.5.2 插件卡片

每张卡片展示以下字段，并带两个按钮：安装、查看详情。

| 字段 | 说明 |
|---|---|
| 图标 | 插件包声明的图标，缺省时用默认图标 |
| 插件名 | 元信息中的显示名 |
| 版本 | 语义化版本 |
| 描述 | 元信息中的描述，超出两行折叠 |
| 标签 | 元信息中的标签数组 |
| 作用域徽标 | 只展示插件声明支持的作用域，分全局、用户、账号三种 |
| 数据范围徽标 | 仅本作用域（常规色）或全系统数据（红色） |
| 出网主机 | 折叠展示，展开后列出全部hosts；未声明出网时显示“禁止出网” |
| 钩子摘要 | 折叠展示，分两部分：订阅了哪些事件、在哪些检查点拦截 |
| 加载状态 | 已加载 / 加载失败 / 待更新 |

#### 4.5.3 全系统数据插件的禁用态

数据范围为全系统的插件：

- 普通用户看到的是“不可安装”的禁用态
- 卡片整体标红
- 卡片上注明“需要管理员安装”
- 安装按钮隐藏，保留查看详情

#### 4.5.4 操作

- 安装 → 弹窗选作用域并填设置
- 查看详情 → 弹窗展示插件元信息、设置schema、钩子清单、出网声明

安装弹窗：

| 步骤 | 内容 |
|---|---|
| 1. 选择作用域 | 只在插件声明支持的作用域内可选；只有一个可选时自动选中且不展示选择器 |
| 2. 选择账号 | 作用域为账号级时必填，列出当前用户自己的账号 |
| 3. 填写设置 | 按设置schema自动渲染，按分组展示，敏感字段用密码框 |
| 4. 设定优先级 | 预填插件声明的默认值，可改，数值小者先执行 |
| 5. 确认 | 提交后绑定立即生效 |

安装规则：

| 情况 | 表现 |
|---|---|
| 作用域只支持全局 | 用户端不展示安装入口，提示需要管理员安装 |
| 数据范围为全系统 | 用户端不展示安装入口，卡片标红并注明需要管理员安装 |
| 同一作用域已有绑定且不允许重复 | 提示将覆盖原绑定，需二次确认 |
| 插件加载失败 | 不可安装，入口置灰并展示失败原因 |
| 必填设置未填 | 表单红字提示，不能提交 |

说明：

- 插件市场只列插件包，不列策略
- 用户只能安装声明了用户级或账号级作用域的插件
- 安装后前往我的插件页管理

### 4.6 我的插件

路径： /my-plugins

本页为新增页面，列出用户自己创建的插件绑定。

结构：

顶部：

- 标题“我的插件”
- 筛选：作用域、启用状态
- 按钮：去插件市场

列表：

| 列 | 说明 |
|---|---|
| 插件名 | 点击查看详情 |
| 作用域 | 用户级 / 账号级；账号级附带账号名 |
| 启用状态 | 已启用 / 已停用 / 已自动停用 / 已失效 |
| 优先级 | 数字，数值小者先执行 |
| 健康度摘要 | 调用次数 / 异常次数 |
| 操作 | 启用或停用、编辑设置、改优先级、删除、查看健康度 |

生效提示：

- 同一插件在账号级与全局级都有绑定时，实际生效的是账号级那一份
- 页面在该插件的行上提示“账号级绑定生效，全局绑定被覆盖”
- 全局绑定由管理员配置，用户端只读展示，不可修改

操作：

- 启用或停用 → 立即生效
- 编辑设置 → 弹窗按设置schema渲染，提交后立即生效
- 改优先级 → 弹窗填数字
- 删除 → 二次确认，删除后立即生效
- 查看健康度 → 弹窗展示调用次数、异常次数、平均耗时、最近错误

空状态：

| 元素 | 内容 |
|---|---|
| 主文案 | 还没有安装任何插件 |
| 次文案 | 进入插件市场选择插件，点击安装，选好作用域并填写设置即可 |
| 主按钮 | 去插件市场 |

### 4.7 实例页

路径： /instances

结构：

顶部：

- 标题“我的实例”
- 搜索框
- 筛选：状态、模拟/实盘、策略、账号
- 按钮：新建实例
- 批量操作：批量启动、批量停止

列表：

| 列 | 说明 |
|---|---|
| 实例名 | 点击进详情 |
| 策略 | 策略名 |
| 交易对 | symbol |
| 账号 | 账号名 / “模拟盘” |
| 模式 | 模拟/实盘 |
| 状态 | 运行中 / 已停止 / 错误 |
| 净值 | 模拟盘从引擎拿，实盘从币安算 |
| 收益率 | 计算 |
| 运行时长 | 计算 |
| 最近活动 | 时间 |
| 操作 | 启动/停止、编辑、删除 |

行内操作：

- 启动 / 停止
- 暂停 / 恢复
- 编辑参数 → 弹窗（需停止）
- 换策略 → 弹窗（需停止 + 平仓）
- 查看详情
- 删除 → 二次确认

### 4.8 实例详情页

路径： /instances/{id}

顶部：

- 实例名
- 状态标签
- 策略名
- 交易对
- 账号
- 操作按钮：启动/停止、暂停/恢复、平仓、编辑、换策略、删除

#### 4.8.1 Tab


1. 概览
   - 净值卡片（大数字）
   - 收益率、最大回撤、运行时长
   - 净值曲线（模拟盘从快照拿，实盘推算）
   - 持仓摘要（前几个）
   - 最近订单（前几条）
   - 当前参数（只读）
2. 持仓
   - 持仓清单（表格）
   - 每行：标签、方向、数量、开仓价、标记价、盈亏、盈亏率、操作（平仓）
   - 顶部：一键全平、平选中
   - 平仓弹窗：数量输入框（默认满仓）
3. 订单
   - 订单列表
   - 筛选：状态、方向、时间
   - 分页
4. 日志
   - 日志列表
   - 筛选：等级、时间
   - 实时更新（WebSocket）
   - 自动滚动到底部（可关闭）
5. 参数
   - 显示当前参数
   - 编辑按钮（需停止实例）
   - 根据schema自动渲染表单
6. 审计
   - 该实例的审计日志
7. 分享
   - 分享token列表
   - 生成分享链接
   - 撤销分享链接
   - 每个链接的访问统计

#### 4.8.2 操作与说明

操作：启动/停止、暂停/恢复、平仓（单个/多个/全部）、编辑参数、换策略、生成分享、删除。

说明：

- 实例只关联策略，不关联插件
- 实例页不展示任何插件信息
- 插件挂在作用域上，不在实例上，实例的运行不受插件增删的影响

## 九、权限对页面的影响

### 9.1 菜单可见性

- user：看不到管理员的菜单
- admin：看到管理员菜单
- super_admin：看到全部

### 9.2 按钮可见性

- 用户不能强停实例 → 不显示强停按钮
- 管理员不能删用户 → 不显示删除按钮
- super_admin才能看到备份按钮

### 9.3 数据范围

- user：只显示自己的数据
- admin：显示所有数据
- 前端不做数据过滤，靠后端

### 9.4 策略与插件的权限

| 场景 | 表现 |
|---|---|
| 策略页 | 所有登录用户只读可见，无上传入口、无删除入口 |
| 插件市场 | 数据范围为全系统的插件，用户端安装入口置灰，提示需要管理员安装 |
| 安装插件 | 只能选插件声明支持的作用域，且只能是用户级与账号级 |
| 我的插件 | 只显示自己创建的绑定，全局绑定只读展示 |
| 策略管理Tab | 仅admin与super_admin可见 |
| 插件管理Tab | 仅admin与super_admin可见 |
| 全局绑定 | 仅管理员可建、可改、可停用 |
| 卸载插件 | 仅管理员可操作 |
| 重新扫描扩展 | 仅管理员可操作 |

## 十四、前端的结构约束

### 14.1 前后端分离

- 前端只做展示与交互
- 鉴权、数据范围过滤、参数校验的最终判定都在后端
- 前端不直接访问交易所，也不直接访问数据库

### 14.2 页面随声明自动生成

- 实例参数表单按策略的参数schema渲染
- 插件设置表单按插件的设置schema渲染
- schema新增字段时页面无需单独改造

### 14.3 状态由后端决定

- 实例状态、订单状态、绑定状态、加载状态均以后端返回为准
- 前端不做状态的本地推断
- 乐观更新仅用于启停这类可快速确认的操作

### 14.4 实时优先、轮询兜底

- 页面数据默认由推送驱动
- 长连接不可用时降级为轮询
- 轮询间隔可配

### 14.5 统一的交互约定

- 危险操作一律二次确认
- 列表一律可筛选、可分页
- 空状态一律给出下一步引导
