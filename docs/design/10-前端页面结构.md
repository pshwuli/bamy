BAMY 前端页面结构

本文档是 BAMY 框架的第十份设计文档，定义：前端有哪些页面、每个页面展示什么、每个页面能做什么操作、页面之间的跳转关系、权限如何影响页面、交互细节如何规范。
不写代码，只写结构。本文档是完整设计，不是第一版，是最终态。

一、文档要回答的问题

1. 前端分为几个区域
2. 每个角色看到哪些页面
3. 每个页面的结构是什么
4. 每个页面的字段从哪来
5. 每个页面的操作是什么
6. 页面之间怎么跳转
7. 权限如何影响页面
8. 实时更新怎么做
9. 错误和空状态怎么展示
10. 响应式怎么做

二、前端的整体结构

2.1 三个区域

区域 用户 说明
认证区 未登录用户 注册、登录、找回密码
用户后台 普通用户 看自己的账号、实例、模拟盘
管理员后台 管理员 看所有人的，运维全局
访客视图 任何有分享 token 的人 只读看一个盘

2.2 角色与页面的对应

页面 guest user admin super_admin
注册/登录 ✓ - - -
用户后台 - ✓ ✓ ✓
管理员后台 - - ✓ ✓
超级管理员后台 - - - ✓
访客视图 ✓ ✓ ✓ ✓

2.3 前端的整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                        顶栏                                   │
│  Logo | 通知 | 用户菜单 | 主题切换                            │
├──────────┬───────────────────────────────────────────────────┤
│          │                                                   │
│  侧边栏  │                    主内容区                       │
│          │                                                   │
│  导航菜单 │              （每个页面渲染在这里）                │
│          │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│                        底部状态栏（可选）                     │
│  引擎状态 | 版本号 | 当前时间                                 │
└──────────────────────────────────────────────────────────────┘
```

2.4 响应式断点

断点 宽度 布局
桌面 ≥ 1280px 侧边栏展开
平板 768-1279px 侧边栏折叠
手机 < 768px 侧边栏抽屉

八、实时更新

8.1 WebSocket 连接

· 登录后自动连接 /ws/user
· 管理员连接 /ws/admin
· 访客连接 /ws/view/{token}

8.2 订阅机制

· 前端按需订阅主题
· 进入页面时订阅，离开时取消
· 订阅示例：instance.1.orders、account.1.balance

8.3 推送处理

· 收到推送 → 更新对应组件
· 不刷新整页
· 关键事件弹通知

8.4 断线重连

· 自动重连
· 重连后重新订阅
· 展示连接状态

8.5 降级

· WebSocket 不可用 → 轮询
· 轮询间隔可配

九、权限对页面的影响

9.1 菜单可见性

· user：看不到管理员的菜单
· admin：看到管理员菜单
· super_admin：看到全部

9.2 按钮可见性

· 用户不能强停实例 → 不显示强停按钮
· 管理员不能删用户 → 不显示删除按钮
· super_admin 才能看到备份按钮

9.3 数据范围

· user：只显示自己的数据
· admin：显示所有数据
· 前端不做数据过滤，靠后端

9.4 越权处理

· 用户手动改 URL 访问管理员页 → 后端返回 404 → 前端跳转错误页
