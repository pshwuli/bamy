BAMY 接口契约

本文档是 BAMY 框架的第九份设计文档，定义：系统对外暴露的全部接口，包括 HTTP REST 接口和 WebSocket 接口，涵盖认证、账号、插件、实例、订单、持仓、模拟盘、对账、风控、审计、系统、分享。
不写代码，只写契约。本文档是完整设计，不是第一版，是最终态。

二、接口的整体规范

2.1 接口分类

类别 前缀 鉴权 数据范围
认证 /api/auth/* 无 注册、登录、找回密码
初始化 /api/setup 无（首次） 创建第一个管理员
用户 /api/* JWT 强制按 owner_id 过滤
管理员 /api/admin/* JWT + 角色≥admin 全局
超级管理员 /api/super/* JWT + super_admin 全局 + 系统级
访客 /view/{token} 分享 token 只读，只限该 token 绑定的实例
系统 /health、/metrics 无 健康检查、监控
WebSocket /ws/* JWT 或分享 token 实时推送

2.2 命名规范

· 路径用小写 + 中划线（如 /api/strategy-instances）
· 或小写 + 复数（如 /api/instances），统一用复数
· 动作用子路径（如 /api/instances/{id}/start）
· 不用动词做路径（除特殊动作）

2.3 HTTP 方法

方法 用途
GET 查询
POST 创建、执行动作
PUT 全量更新
PATCH 部分更新
DELETE 删除

2.4 请求格式

· Content-Type：application/json
· 认证：Authorization: Bearer <token>
· 请求 ID：X-Request-Id（可选，用于追踪）
· 时间戳：ISO 8601 格式

2.5 响应格式

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "request_id": "xxx",
  "timestamp": 1690000000000
}
```

错误响应：

```json
{
  "code": 40001,
  "message": "参数错误",
  "errors": [
    {"field": "amount", "reason": "必须大于0"}
  ],
  "request_id": "xxx",
  "timestamp": 1690000000000
}
```

2.6 HTTP 状态码

状态码 含义
200 成功
201 创建成功
204 成功无内容
400 请求参数错误
401 未认证
403 无权限
404 资源不存在（或被隔离）
409 冲突（如重复创建）
422 参数校验失败
429 请求过频
500 服务器错误
503 服务不可用

2.7 业务错误码

错误码规范：HTTP状态码 × 1000 + 序号

错误码 含义
40001 参数错误
40002 参数类型错误
40003 参数范围错误
40004 必填参数缺失
40005 参数依赖不满足
40101 未登录
40102 Token 无效
40103 Token 过期
40104 用户名或密码错误
40105 账号被锁定
40106 账号被禁用
40301 无权限
40302 角色不足
40303 被隔离（返回 404 伪装）
40401 资源不存在
40901 资源冲突
40902 状态冲突
42201 业务校验失败
42901 请求过频
50001 内部错误
50002 数据库错误
50003 外部服务错误
50301 服务不可用

2.8 分页规范

请求参数：

参数 说明 默认
page 页码（从 1 开始） 1
page_size 每页数量 20
cursor 游标（用于大数据集） -
sort 排序字段 created_at
order 排序方向（asc/desc） desc

响应格式：

```json
{
  "code": 0,
  "data": {
    "items": [ ... ],
    "pagination": {
      "page": 1,
      "page_size": 20,
      "total": 1000,
      "total_pages": 50,
      "has_next": true,
      "has_prev": false,
      "next_cursor": "xxx"
    }
  }
}
```

2.9 接口版本

版本通过 URL 路径体现，路径中不带版本号时视为当前版本：

| 形态 | 说明 |
|---|---|
| `/api/instances` | 当前版本，等价于最新版本 |
| `/api/v1/instances` | 显式指定第一版 |
| `Accept: application/vnd.bamy.v1+json` | 通过请求头指定版本 |

规则：

· 同一接口同时支持路径与请求头两种指定方式，两者冲突时以路径为准
· 向后兼容的变更不升版本号：新增字段、新增接口、放宽取值范围
· 破坏性变更升版本号：删除字段、改变字段语义、改变必填性、改变状态机
· 旧版本保留至其调用方全部迁移完成，保留期内新旧版本并存
· 响应头返回当前生效的版本，便于调用方确认
· 已废弃版本在响应中带废弃提示，并在文档中标注

2.10 幂等性

· GET、PUT、DELETE 天然幂等
· POST 通过 client_order_id 或请求 ID 实现幂等
· 支持幂等的接口需在契约中注明

十七、限流规则

接口 限制
/api/auth/login 每 IP 每分钟 10 次
/api/auth/register 每 IP 每小时 5 次
/api/auth/forgot-password 每邮箱每小时 3 次
/api/* 每用户每分钟 120 次
/api/admin/* 每管理员每分钟 300 次
/api/super/* 每 super_admin 每分钟 300 次
/view/{token} 每 token 每分钟 60 次
WebSocket 每连接每分钟 100 条消息

超限返回 429 和 Retry-After 头。

十八、接口的幂等性

接口 幂等方式
POST /api/accounts 通过 name 唯一约束
POST /api/instances 通过 (owner_id, name) 唯一约束
POST /api/instances/{id}/start 状态幂等（running 时返回已运行）
POST /api/instances/{id}/stop 状态幂等
POST /api/instances/{id}/positions/*/close 通过 client_order_id
POST /api/orders/{id}/cancel 状态幂等

十九、接口的版本兼容

19.1 兼容性承诺

· 新增字段：兼容
· 新增接口：兼容
· 修改字段类型：不兼容（升版本）
· 删除字段：不兼容（升版本）
· 修改接口语义：不兼容（升版本）

19.2 废弃策略

· 标记废弃的接口保留 6 个月
· 6 个月后移除
· 废弃期间返回 Deprecation 头

19.3 版本切换

· URL 版本：/api/v1/*、/api/v2/*
· 未指定版本：默认最新
· 客户端可显式指定

二十、接口的安全

20.1 传输安全

· 生产环境强制 HTTPS
· TLS 1.2+

20.2 认证

· JWT 在 Authorization 头
· 不在 URL 里传 token

20.3 CORS

· 生产环境白名单
· 不用 *

20.4 CSRF

· 使用 JWT 而非 Cookie，天然防 CSRF
· 如用 Cookie，需 CSRF token

20.5 输入校验

· 所有输入经 Pydantic 校验
· 不信任客户端
· SQL 参数化

20.6 输出过滤

· 敏感字段脱敏
· 错误信息不泄露内部细节

20.7 请求大小限制

· 默认 1MB
· 文件上传单独处理

20.8 超时

· 客户端超时：30 秒
· 服务端处理：30 秒
· 长任务异步返回
