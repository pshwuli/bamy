BAMY 数据模型

本文档是 BAMY 框架的第八份设计文档，定义：系统有哪些数据、数据怎么组织、表结构、字段、索引、关系、约束、加密、分区、归档、迁移。
不写代码，只写规则和逻辑。本文档是完整设计，不是第一版，是最终态。

五、表之间的关系

5.1 ER 图（文字版）

```
users
  ├─ 1:N → accounts
  ├─ 1:N → instances
  ├─ 1:N → api_tokens
  ├─ 1:N → refresh_tokens
  ├─ 1:N → user_sessions
  ├─ 1:N → share_tokens
  ├─ 1:N → audit_logs (as actor)
  └─ 1:N → risk_rules

accounts
  ├─ N:1 → users
  ├─ 1:N → instances
  ├─ 1:N → account_health
  ├─ 1:N → orders
  └─ 1:N → reconcile_diffs

plugins
  └─ 1:N → instances

instances
  ├─ N:1 → users
  ├─ N:1 → accounts (paper 时 null)
  ├─ N:1 → plugins
  ├─ 1:N → orders
  ├─ 1:N → instance_state
  ├─ 1:N → position_snapshots
  ├─ 1:1 → paper_accounts (paper 时)
  ├─ 1:N → paper_snapshots (paper 时)
  ├─ 1:N → share_tokens
  ├─ 1:N → reconcile_diffs
  └─ 1:N → system_logs

orders
  └─ N:1 → instances

circuit_breakers
  └─ N:1 → accounts / users (target)

share_tokens
  └─ 1:N → share_access
```

5.3 冗余字段

部分表冗余存储 owner_id，目的是：

· 加快用户级查询（不用 join）
· 便于权限过滤
· 减少多表关联

冗余字段必须保持一致：主表更新时，冗余字段跟随更新。

六、索引设计

· 主键自带索引

· 不建冗余索引
