现象：

  - InstancePatch.paper_config 类型正确指向 PaperConfigIn（第 281 行）

  2) 快照只在「有变化」或「有持仓」时写，避免空跑堆积；
  3) 最大回撤改为遍历快照序列计算，与模拟盘统一口径；
  4) 前端净值曲线对 paper=false 也走同一渲染逻辑；
  5) 历史数据缺失时，UI 明确提示「实盘净值自 X 时起开始记录」，

6/6 笔订单 rejected

pm = ex.fapiPrivateGetPositionSideDual()
hedge = bool(pm.get("dualSidePosition"))
params = {"positionSide": "LONG"} if (hedge and market == "swap") else {}

BUG-3　批量启停接口永远返回 400
现象
POST /api/instances/batch/stop
→ 400 {"code":40002,"message":"参数类型错误",
   "errors":[{"field":"instance_id",
   "reason":"Input should be a valid integer, unable to parse string as an integer"}]}

三种参数格式全部失败：{"instance_ids":[...]} / {"ids":[...]} / {"instance_id":N}
根因（已定位）
backend/bamy/api/instances.py 路由注册顺序冲突：
第350行  @router.post("/api/instances/{instance_id}/stop")    ← 先注册
第377行  @router.post("/api/instances/batch/{action}")        ← 后注册

FastAPI 按注册顺序匹配，/api/instances/batch/stop 先命中 {instance_id}/stop，把字符串 "batch" 当 int 解析失败。第 377 行的批量路由永远进不去。
验证证据
POST /api/instances/batch/stop  → 400（instance_id 无法解析为整数）
POST /api/instances/5/stop      → 200（同一路由，数字 id 正常）

修复建议
任选其一：
1) 把 /api/instances/batch/{action} 提到所有 {instance_id} 路由之前注册
2) 改用不冲突的路径：/api/instances/batch-action/{action}
3) 给 instance_id 加路径约束（Path 校验 gt=0 或使用 :int 转换器）
